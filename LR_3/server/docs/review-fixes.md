# Исправления замечаний преподавателя

1. V4: PostgreSQL ENUM user_role, адаптер RoleConverter для EclipseLink.
2. V5: дополнительные CHECK; подробная таблица в database-validation.md.
3. API студентов: /api/students и /api/students/{isu} во всех компонентах.
4. testing/ и test.cmd: отдельный Docker-проект, временная БД, Java-сервер,
   frontend, автоматическая очистка. Рабочая БД не подключается.
5. Logout требует access Bearer и проверяет владельца переданного refresh.
   Refresh проверяет подпись, назначение, срок, хеш, отзыв и владельца токена;
   если передан access Bearer, пользователь должен совпадать. Без access
   действительный refresh остаётся самостоятельным секретом для обновления
   истёкшего access. Получить чужой токен только по ID пользователя нельзя.
   Кража действительного refresh по-прежнему означает компрометацию сессии.
   Добавлен тест двух пользователей: чужие refresh/logout возвращают 403,
   logout без access — 401; отказ не отзывает сессию владельца.
6. @Hidden удалён. Публичный Swagger использует явный YAML-контракт.
   Автосканирование контроллеров исключено через packages-to-scan, потому что
   нестандартный QUERY иначе создаёт ошибочные операции. Контракт проверяется
   тестами; это не автоматически генерируемая документация контроллеров.
7. POST/PUT принимают StudentWriteRequest, QUERY — StudentQueryRequest.
   PATCH имеет типизированные поля и набор присутствующих свойств: пропуск
   сохраняет значение, null очищает необязательное поле, false не теряется.
   Неизвестное поле PATCH даёт ошибку 422, а не молчаливое игнорирование.
8. Простые правила студентов перенесены в аннотации DTO: обязательность,
   диапазоны и шаблоны. Они проверяются Validator в сервисе после нормализации,
   включая вызовы вне HTTP. Необязательные Integer допускают null. Для заметок
   CodePointSize считает Unicode-символы, а не UTF-16 единицы. Совместное
   заполнение полей заселения и границы даты проверяются отдельно.
   Jackson запрещает усечение дробей в целые числа и неявное превращение
   чисел в boolean/строки. Ошибки полей имеют единый ответ API.
9. SQLSTATE получили имена; HTTP-коды в обработчике выражены через HttpStatus.
10. Преобразования студента, PATCH и пользователя собраны в StudentMapper.
    Преобразование PATCH через entity → response → JSON → DTO удалено.
    StudentInputParser остаётся для импорта и GET-параметров; это разбор ввода,
    а не mapper сущностей.
11. BCryptPasswordEncoder генерирует случайную соль при каждом хешировании.
    Она встроена в password_hash. Отдельный столбец не нужен.

## Просмотр БД и соли на защите

Из LR_3:

```powershell
.\db.cmd --users
.\db.cmd
```

Первая команда показывает ID, логин, email, роль, параметры BCrypt и соль
(22 символа с позиции 8). Полный хеш/исходный пароль не выводятся. Команда
подключается к рабочей базе, не к временной тестовой. Она поднимает только
PostgreSQL, не сервер приложения; миграции применяет start.cmd.

В интерактивном psql:

```sql
\dt
\d app_users
\d students
SELECT enum_range(NULL::user_role);
SELECT id, username, role FROM app_users;
\q
```

Дополнительный клиент БД не нужен: psql уже есть внутри контейнера.
Пароль подключения берётся из приватного server/.env, не печатается.
